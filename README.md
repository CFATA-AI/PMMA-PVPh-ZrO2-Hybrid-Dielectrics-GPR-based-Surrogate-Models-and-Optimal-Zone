# PMMA-PVPh-ZrO2-Hybrid-Dielectrics-GPR-based-Surrogate-Models-and-Optimal-Zone
This repository contains the Python codes used to train the Gaussian Process Regressions urrogate models of capacitance density and leakage current density across the PMMA/PVPh-ZrO2 ternary space, and to identify the optimal compositional zone through an entropy- and uncertainty-weighted score.
